# 《人生岔路》教师 5–10 分钟快速体验路线

> 在线入口：https://life-branch-stories.jilombmiker.chatgpt.site  
> 教师文档：https://life-branch-stories.jilombmiker.chatgpt.site/product-docs

## 1. 一分钟确认产品规模

打开首页，观察三个内容层级。

- 小型世界：4 部、72 幕、20 个结局，适合一晚完成。
- 中型世界：5 部、228 幕、35 个结局，包含三名固定人物和一名动态人物。
- 大型连续世界：2 部、200 幕、16 个结局，读取九界正史。

首页共显示 11 部故事、500 幕、71 个结局。无需登录，进度保存在当前浏览器。

## 2. 三分钟体验 M04《盐月沉入森林》

进入“中型世界”中的 M04。

建议观察四点。

1. 玩家是被森林异族养大的人类孩子，跨族养育是真实亲子关系。
2. 人类依赖燃烧土地真名维持粮食和供暖，因此不能简单要求人类立即停用魔法。
3. 森林持续失去栖息地，盐裔又依赖污染残渣生存，任何方案都会影响具体族群。
4. 玩家可以缔结跨族誓约，但每次都会永久失去一个日常词语。

第一幕结束后，检查三个选项是否都写明收益和代价；再打开人物或世界档案，观察关系、资源和永久事实如何被记录。

## 3. 三分钟体验 L01《九个世界没有共同的明天》

返回首页，进入“大型连续世界”中的 L01。

建议观察五点。

1. 玩家身份为“九界通道仲裁员”，拥有配额和复核权，但不能创造容量或替世界同意。
2. 通道只剩三成容量，开启一条高载路线必须具名另一条被延迟路线。
3. 没有旧存档时，页面使用并标明作者默认历史；有旧存档时读取玩家选择的九界正史。
4. 旧世界的制度、人物公共命运和世界伤痕会进入大型世界，但姓名和自由输入原文不会上传或继承。
5. 两名旧角色会根据正史成为动态见证者，承担真实证词或制度职责，不只是彩蛋。

## 4. 两分钟抽查产品质量证据

进入“产品文档”，打开《72 条结构化测评集》，建议抽查以下案例。

- EV-037 / EV-038：同一组词语中出现相反否定，系统必须执行不同路线。
- EV-021—EV-025：人物死亡、人格中断、失权、失词和世界损失不能被后文撤销。
- EV-060：旧浏览器存档缺少新增字段时仍能安全继续。
- EV-061：L01 只读九界正史，不覆盖旧档。
- EV-062：L02 同时继承九界与 L01。
- EV-071：正式构建和自动测试必须记录通过数与失败数。

## 5. 建议向学生追问的问题

1. 为什么运行时选择可复现的本地语义路由，而没有把远程大模型设为必需依赖？
2. 为什么“叙事因果与永久事实”在100分评分中占最高的25分？
3. 如何避免高好感值把人物变成完全服从玩家的工具？
4. 九界继承为什么只传公共后果，不传玩家自由输入原文和私人关系数值？
5. 哪些测试能证明产品可靠，哪些问题仍必须依靠真实玩家试玩？

## 6. 最短审阅结论路径

若课堂时间不足，只需完成以下顺序。

`首页规模 → M04第一幕 → L01第一幕 → EV-037 → EV-061 → 测试报告结论`

这条路线能够同时看到产品定位、故事设计、AI输入边界、旧存档兼容、跨世界连续性和质量证据。
