## 1. 使用说明

每条案例包含编号、目标、前置状态、操作与输入、预期结果、评分/严重度和证据。`A` 表示自动化，`H` 表示人工专家检查，`U` 表示真实用户试玩。P0 失败直接 Block；P1 失败进入提交前修复；P2 为非阻断优化。

评分不按 72 条简单平均。案例通过后，为《测评标准》对应子项提供证据；部分通过按该子项 50% 计，失败计 0。P0 无论数值总分多少都一票否决。

## 12. 首次玩家试玩任务

1. 不看说明人的帮助，打开公开链接并选择一部小型世界。
2. 阅读第一幕后说明玩家身份、眼前危机、两名重要人物和最主要代价。
3. 完成第一章，指出一个前面选择在后面留下的影响。
4. 在关键节点写一句含否定、对象或优先级的自由输入。
5. 打开关系、线索、术语和永久事实档案。
6. 回到一个检查点建立新分支，再确认原分支仍在。
7. 导出存档，刷新页面并确认自动恢复。
8. 通关后说明最记得的人物、其最后行动和故事留下的问题。

记录任务是否完成、用时、帮助次数、澄清次数、结局、人物复述质量和1–5分回味评分。默认不保存或上传玩家自由输入原文。
